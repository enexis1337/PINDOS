Правило для всех будущих изменений в boot.rs, entry.rs, linker.ld/link.ld:

Перед любым изменением — git commit текущего рабочего состояния, если ещё не закоммичено.
После каждого изменения — обязательно python drun.py -T и проверка реального текста вывода COM1 (не пересказ, а сырой текст).
Если вывод регрессировал (короче чем был, или появился triple fault) — немедленно git checkout -- <файлы> откат, не "чинить дальше" поверх сломанного.
Сделать коммит с понятным сообщением и синхронизировать изменения на гит сразу после подтверждения что drun -T даёт чистый вывод.
Никогда не удалять debug-инструменты (debug-байты, отладочные kprintln) пока новая версия не подтверждена в QEMU минимум 1 раз.

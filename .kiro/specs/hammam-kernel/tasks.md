# Implementation Plan: Hammam Kernel

## Overview

Реализация монолитного ядра Hammam для архитектуры x86/x86-64 в составе ОС PINDOS.
Задачи упорядочены по зависимостям: сначала базовая инфраструктура (загрузка, GDT/IDT, VMM),
затем подсистемы верхнего уровня (VFS, сеть, POSIX), в конце — интеграция и тесты.
Язык реализации: **C** (ядро) + **NASM/GAS** (ассемблерные вставки).

## Notes

- Задачи, помеченные `*`, являются опциональными и могут быть пропущены для ускорения MVP
- Каждая задача ссылается на конкретные требования для обеспечения трассируемости
- Контрольные точки обеспечивают инкрементальную валидацию на каждом этапе
- Property-тесты реализуются с использованием библиотеки **Theft** (C, без внешних зависимостей)
- Unit-тесты и property-тесты дополняют друг друга: unit-тесты проверяют конкретные примеры, property-тесты — универсальные инварианты
- Порядок задач отражает зависимости: VMM должен быть готов до VFS; HAL — до Network Stack; Scheduler — до POSIX Layer
